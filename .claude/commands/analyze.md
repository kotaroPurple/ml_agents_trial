---
description: CSVを分析して src/ml_agents_trial/eda/ にコードを生成・実行する。タスク種別（分類/回帰）を自動判定し EDA サマリーを artifacts/eda/ に保存する。引数でCSVパスとターゲット列を指定可能。
---

`$ARGUMENTS` の形式: `[CSV_PATH] [TARGET_COLUMN]`
- CSV_PATH 未指定: `data/raw/house_prices.csv`
- TARGET_COLUMN 未指定: `MedHouseVal`

## Step 1 — subagent によるコード生成

@data-analyst を呼び出して次の指示を渡してください:
「CSV: `[CSV_PATH]`, ターゲット列: `[TARGET_COLUMN]` を分析して、`src/ml_agents_trial/eda/` に EDA モジュールを実装してください。ファイル構成はデータ規模に合わせて判断してください。実装すべき公開関数:
- `summarize_dataset(df, target) -> dict`
- `detect_task_type(df, target) -> str`（'regression' or 'classification'）
- `find_top_features(df, target, n=10) -> list[str]`
- `plot_distributions(df, output_dir)` / `plot_correlation_heatmap(df, target, output_dir)`

生成後に実行して `artifacts/eda/data_summary.json` が作成されることを確認してください。」

## Step 2 — 構造チェック

@code-reviewer を呼び出して次の指示を渡してください:
「`src/ml_agents_trial/eda/` 内の全 .py ファイルを構造チェックしてください」

FAIL が返ってきた場合は @data-analyst に修正を依頼してから Step 3 に進んでください。

## Step 3 — ドメインレビュー

```bash
find src/ml_agents_trial/eda/ -name "*.py" | sort
```
で生成ファイルを確認し、各ファイルを Read して以下を確認してください:
- `summarize_dataset`, `detect_task_type`, `find_top_features` が実装されているか
- `detect_task_type` がターゲット列の型・ユニーク数から適切に判定しているか

問題があれば @data-analyst に修正を依頼してください。

## Step 4 — 実行・可視化

```bash
.venv/bin/python src/ml_agents_trial/eda/analysis.py [CSV_PATH] [TARGET_COLUMN]
.venv/bin/python -c "
from ml_agents_trial.core.io import load_csv
from ml_agents_trial.eda.plots import plot_distributions, plot_correlation_heatmap
from ml_agents_trial.core.config import ARTIFACTS_EDA
df = load_csv('[CSV_PATH]')
plot_distributions(df, ARTIFACTS_EDA / 'plots')
plot_correlation_heatmap(df, '[TARGET_COLUMN]', ARTIFACTS_EDA / 'plots')
print('plots saved')
"
```

## Step 5 — git コミット

```bash
git add src/ml_agents_trial/eda/
STAGED=$(git diff --name-only --cached | grep 'ml_agents_trial/eda/' | sed 's|src/ml_agents_trial/eda/||')
git commit -m "feat(eda): generate EDA modules

Generated by /analyze command (target: [TARGET_COLUMN]):
$(echo "$STAGED" | sed 's/^/- /')"
```

- タスク種別（分類/回帰）

- コミットハッシュ（`git log --oneline -1`）
- 次のステップ: `/engineer [TARGET_COLUMN]` を実行してください
