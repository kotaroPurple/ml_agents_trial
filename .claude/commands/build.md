`$ARGUMENTS` の形式: `[TARGET_COLUMN]`（未指定: `MedHouseVal`）

## 前提確認

`data/processed/features.csv` が存在するか確認してください。
存在しない場合は「先に `/engineer` を実行してください」と伝えて終了。

## Step 1 — subagent によるコード生成

@model-architect を呼び出して次の指示を渡してください:
「`artifacts/eda/data_summary.json` の `task_type` を読んでタスク種別を確認し、`src/ml_agents_trial/models/` に学習モジュールを実装してください。ファイル構成はモデル数・複雑さに合わせて判断してください。実装すべき内容:
- モデル設定（クラスパス + ハイパーパラメータ）の定義（回帰: Ridge/RandomForest/HistGradientBoosting/LGBM、分類: 対応する Classifier）
- `train_model(name, config, X_train, y_train, X_test, y_test) -> dict`
- `train_all(X_train, y_train, X_test, y_test) -> dict`（全モデル学習 + `artifacts/models/comparison.json` 保存）

ターゲット列: `[TARGET_COLUMN]`。生成後に実行して `artifacts/models/comparison.json` を作成してください。」

## Step 2 — 構造チェック

@code-reviewer を呼び出して次の指示を渡してください:
「`src/ml_agents_trial/models/` 内の全 .py ファイルを構造チェックしてください」

FAIL が返ってきた場合は @model-architect に修正を依頼してから Step 3 に進んでください。

## Step 3 — ドメインレビュー

```bash
find src/ml_agents_trial/models/ -name "*.py" | sort
```
で生成ファイルを確認し、各ファイルを Read して以下を確認してください:
- `task_type` に合ったモデルが選ばれているか（回帰なら Regressor、分類なら Classifier）
- `from ml_agents_trial.core.metrics import compute_xxx_metrics` を使っているか
- 各モデルが `artifacts/models/{name}/model.pkl` と `metrics.json` を保存しているか

問題があれば @model-architect に修正を依頼してください。

## Step 4 — ML品質レビュー

@ml-reviewer を呼び出して次の指示を渡してください:
「`models` フェーズの ML 品質レビューを実施してください。
対象: `src/ml_agents_trial/models/`, `artifacts/eda/data_summary.json`, `artifacts/models/comparison.json`」

FAIL が返ってきた場合は @model-architect に修正を依頼し、Step 2 から再確認してください。

## Step 5 — 実行

```bash
.venv/bin/python src/ml_agents_trial/models/trainer.py [TARGET_COLUMN]
```

## Step 6 — 結果表示

```bash
.venv/bin/python -c "
import json
from rich.table import Table
from rich.console import Console
data = json.loads(open('artifacts/models/comparison.json').read())
c = Console()
t = Table(title='Model Comparison')
[t.add_column(k) for k in ['model','rmse','mae','r2','train_time_sec']]
[t.add_row(*[str(row.get(k,'-')) for k in ['model','rmse','mae','r2','train_time_sec']]) for row in data]
c.print(t)
"
```

## Step 7 — git コミット

```bash
git add src/ml_agents_trial/models/
STAGED=$(git diff --name-only --cached | grep 'ml_agents_trial/models/' | sed 's|src/ml_agents_trial/models/||')
git commit -m "feat(models): generate model configs and trainer

Generated by /build command (target: [TARGET_COLUMN]):
$(echo "$STAGED" | sed 's/^/- /')"
```
